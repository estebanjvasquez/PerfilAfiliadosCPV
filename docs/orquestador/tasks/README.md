# Tareas del orquestador

Cada tarea asignada por el orquestador (ChatGPT) vive acá como un archivo
`000N-slug-descriptivo.md`, con el número de `TASK-000N` correspondiente.

- El contenido de cada archivo es el prompt íntegro del orquestador para esa tarea, tal
  como fue entregado — no un resumen ni una reformulación.
- `docs/orquestador/current_task.md` apunta siempre a la tarea activa.
- Ver `docs/orquestador/PROTOCOL.md` para el orden de lectura y la máquina de estados.

`TASK-0001` no tiene archivo formal en esta carpeta — corresponde al trabajo de Fase C
(Canonical Concept Builder `--apply`) ejecutado antes de que este canal existiera; su
resultado está documentado en `audit/phase3_phase_c_apply.md` y en el handoff.
